# Crypto Universe

## Introduction

Metaverse World webapp with modern and beautiful interface developed with React, Vite, Framer Motion, and Tailwind CSS.

## App Features

-   Using React and Vite to build the webapp.
-   Creating a User Interface with Tailwind for design and Framer Motion for animation.

## Development

```
npm install
npm run dev        # Vite dev server
npm run build      # static build → out/
npm run preview    # preview the built out/ folder
```

`vite.config.mjs` sets `base: './'`, so the contents of `out/` can be uploaded to any
subfolder without a hardcoded path prefix.
